# Alcance 

### En este archivo buscaremos sintetizar el alcance del sistema extraido del pdf 
------------
El CRM SOS será una plataforma destinada a centralizar y sistematizar la gestión comercial y la relación con clientes, permitiendo reunir en una única plataforma la información de prospectos, leads, usuarios y clientes, junto con el historial de interacciones, acciones comerciales, estados y evolución durante todo su ciclo de relación.

El sistema deberá transformar las actividades comerciales actualmente dispersas en información estructurada que permita:

- ordenar el seguimiento
- conocer el recorrido completo de un prospecto
- determinar la próxima acción
- automatizar determinados seguimientos
- mejorar la conversión de prospectos
- detectar clientes en riesgo (CHURN)
- analizar los canales de adquisición
- y medir los resultados comerciales
  
El CRM SOS será concebido como una herramienta transversal, y noexclusivamente como una herramienta de Marketing, conectando las áreas de Marketing, Comercial, Atención,
Producto y Dirección

A priori buscamos que este sea para uso interno, pero a la larga debera ser posible venderlo a clientes nuestros que les pueda llegar a servir para sus negocios

Nota: 
  - Todavia no esta hecha la funcionabilidad de que SOS sepa que clientes fueron dados de baja(entiendo yo)

  - Para un MVP se priorizan llegar a las siguientes funcionabilidades
        * Debe ser multiempresa

        * Ficha unificada

        * Prospectos / clientes

        * Historial de interacciones
